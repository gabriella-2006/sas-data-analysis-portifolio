# Projeto 01 - Validação de Dados com SAS 

## Objetivo 
Demonstrar a utilização do SAS para identificar inconsistências em uma base de dados fictícia.
A ideia é aplicar regras de negócio para classificar registros como regulares ou inconsistentes e posteriormente gerar indicadores de analise da qualidade de dados.

## Tecnologias utilizadas
- SAS
- DATASTEP
- PROC SQL
- PROC FREQ
- PROC MEANS

## Etapas do projeto
1. Criação da base de dados
2. Exploração dos dados
3. Aplicação das regras de negócio
4. Identificação de inconsistências
5. Criação de indicadores
6. Análise dos resultados
